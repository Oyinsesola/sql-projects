# Famous People and Co-Star Analysis

## Overview
This SQL project explores relationships between famous people, their studios, and their co-stars. The project uses joins and aggregate functions to analyze collaborations and studio demographics.

## Database Structure

### famous_people
- id
- name
- studio
- age

### costars
- id
- person1_id
- person2_id
- movie

## SQL Skills Demonstrated
- CREATE DATABASE and CREATE TABLE
- INSERT statements
- INNER JOINs
- WHERE filtering
- COUNT() and AVG()
- GROUP BY
- ORDER BY

## Analysis
- Identified co-star relationships
- Found co-stars from the same studio
- Calculated average age by studio
- Counted the number of stars in each studio
- Determined actors with the most co-star appearances
- Identified cross-studio collaborations

## Tools
- MySQL
